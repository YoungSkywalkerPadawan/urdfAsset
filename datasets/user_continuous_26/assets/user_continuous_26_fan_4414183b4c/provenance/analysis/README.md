## 转子候选分区（待孤立三维渲染复核）

`rotor_face_mask.npy` 是与源 98,767 个三角形逐行对应的布尔数组；`True` 表示候选转子。当前为 24,915 面、面积 1.167006 源单位²（整机表面积的 39.612%），完整保留这些原面的位置、UV 和材质。单独使用本数组不会封口、修复源非流形或建立物理间隙。

人工先验来自多视角参考：三片宽弧叶为旋转件，前部装饰盖和细护网固定。初始轴仅用于区域筛选：Blender `X=0,Z=.095`，轴向 `Y`；实际驱动轴由主流程的电机轴拟合给出。

当前可复现脚本为 `refine_rotor_mask.py`：

1. 初选轴向 `Y=[-.255,-.108]`、半径 `<.349`；保留主体最大连通区域和已定位的轮毂小分量，排除确认的薄罩圈、栅条与整个前部装饰盖分量 15。
2. 生成模型在底叶后缘与后护网处融合；仅扩大轴向范围会带走一整圈后网。用共享两面边、相邻法向差不超过 20° 的连续宽叶面，向后延伸至 `Y=-.092` 的候选范围。
3. 用下叶宽面和后缘大面生成投影凸包，允许 1.5 mm（源单位视为米时）的轮廓余量，去掉连带的 102 个护网弧面；最终补回 420 个后缘原面、面积 .017364 源单位²。

这是人工语义范围与几何规则组合的候选分区，不是自动恢复机械语义。`rotor_mask_diagnostics.json` 保存参数、分量、数量与局限，`rotor_mask_diagnostic.png` 显示候选及补回部分。旧的 `propose_rotor_mask.py` 和 `explore_rotor_connectivity.py` 仅为诊断过程，**不要在最终脚本之后重跑旧提案以覆盖当前 mask**。

`rotor_boundary_report.py` 对当前 mask 检查到 282 条转静界面边、279 条转子单面边；最大界面位于下叶后缘，包含度数 4 的融合点，并非单一干净平面循环。`rotor_remaining_tail.png` 显示残留静态区域主要呈细护网弧形；仍须孤立转子多角度渲染及全周真实表面碰撞检查，才能确认叶缘归属、封口与间隙。若为实现运动间隙而重建融合点或调整叶片轴向位置/厚度，应另记修改量，不能称为百分之百几何保真。
